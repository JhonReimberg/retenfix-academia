# Catálogos locais

Esta pasta fica vazia no pacote público de código. Os PDFs e a planilha são baixados sob demanda a partir das fontes oficiais:

```powershell
npm run catalogs:fetch
```

O utilitário lê `src/data/sources.json`, preserva os nomes esperados pelo aplicativo e grava os arquivos aqui. Os documentos continuam sendo materiais de Retenfix, AGEL ou APC; verifique os direitos de uso antes de redistribuí-los.
